# Responsive Internship Board

## About the Project
The Responsive Internship Board is a web application that helps users explore and search internship opportunities easily.

## Features
- Responsive design for desktop and mobile devices.
- Displays internship details using JSON data.
- Search internships by title, domain, location, and skills.
- Filter internships by domain.
- Accessible labels and keyboard navigation.
- Displays a message when no matching internships are found.
- Handles data-loading errors.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON


## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Run `index.html` using the VS Code Live Server extension.
4. Explore internships using the search box and domain filter.
